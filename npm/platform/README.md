# @futurelastic/muster-@PLATFORM@

The prebuilt `muster` binary for @PLATFORM@. It is installed automatically by
[`@futurelastic/muster`](https://www.npmjs.com/package/@futurelastic/muster)
when the machine matches; install that package instead of this one.

Source and documentation: <https://github.com/futurelastic/muster>
